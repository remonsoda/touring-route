# ツーリングルート（試作版）

地図をタップしてツーリングルートを作り、保存し、Googleマップのナビに経由地付きで渡すWebアプリです。

## できること

- 地図をタップ → 経由地を追加（S=出発地、G=目的地、数字=経由地）
- マーカーをドラッグ → 位置を調整／タップ → 削除
- ルートの線をタップ → その区間に経由地を挿入
- 「有料道路を避ける」の切り替え（有料区間は黄色の線で表示）
- 名前を付けて保存、☰ から一覧表示・読み込み・削除
- 「出発」→ Googleマップを開く（経由地9件ごとに区間分け）
- 「現在地から続きを案内」→ 休憩後に、まだ通っていない経由地から再開
- 共有URL（Androidの人も同じルートを開ける）

## iPhoneで使えるようにする手順（無料・Mac不要）

GitHub Pages で公開します。PCのブラウザだけで作業できます。

1. https://github.com でアカウントを作る
2. 右上の「＋」→「New repository」。名前は `touring-route`、**Public** を選んで作成
3. 「uploading an existing file」をクリックし、このフォルダの中身（`index.html` `app.js` `style.css` `manifest.webmanifest` `icons` フォルダ）をまとめてドラッグして「Commit changes」
4. リポジトリの「Settings」→ 左メニュー「Pages」→ Branch を `main`、フォルダを `/ (root)` にして「Save」
5. 1〜2分待つと `https://（ユーザー名）.github.io/touring-route/` で開けるようになります
6. iPhoneの **Safari** でそのURLを開き、共有ボタン →「ホーム画面に追加」

コードを直したら、同じ手順3でファイルを上書きアップロードすれば反映されます。

## 使っている無料サービス

| 用途 | サービス |
|---|---|
| 地図 | 国土地理院 地理院タイル／OpenStreetMap |
| 地図ライブラリ | Leaflet |
| ルート計算 | OSRM（公開デモサーバー） |

公開デモサーバーは個人の試用向けです。たくさんの人で使う段階になったら、自前のサーバーや別サービスへの切り替えを検討します。

## 注意

- 保存したルートはこのiPhoneのアプリ内にだけ保存されます。機種変更に備えて、大事なルートは共有URLをメモに残しておくと安心です。
- Googleマップ側の「ルートオプション」で有料道路の設定を合わせてください（アプリからは指定できません）。

## ファイル構成

- `index.html` … 画面の骨組み
- `style.css` … 見た目
- `app.js` … 動き（経由地の管理、ルート計算、保存、Googleマップへのリンク作成）
- `manifest.webmanifest` / `icons/` … ホーム画面に追加したときの名前とアイコン
